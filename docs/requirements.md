# Начальные требования (User Stories)

1. Я, как участник цепочки поставок (фермер/логист), хочу создавать записи о передаче груза, чтобы фиксировать этот факт в системе.
2. Я, как система, должна вычислять SHA-256 хеш для каждой транзакции и блока, чтобы защитить данные от подделки.
3. Я, как система, должна связывать каждый новый блок с предыдущим через prev_hash, чтобы обеспечить целостность цепочки.
4. Я, как аудитор, хочу запускать проверку валидности, чтобы система точно указывала номер блока и причину, если данные были изменены.
5. Я, как система, должна сохранять цепочку в JSON и загружать её при старте, чтобы данные не терялись.
