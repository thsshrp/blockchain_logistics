# Требования и контракты сетевого взаимодействия (Спринт 4)

Базовый префикс API: `/api/v1`. Формат обмена: `application/json`, кодировка UTF-8.

## 1. Функциональные требования
1. Каждая нода запускается независимо с параметрами `node_id`, `host`, `port`, `storage_path`.
2. Нода регистрирует адреса других нод, проверяя их доступность и совместимость генезис-блока.
3. Нода предоставляет информацию о себе и способна запрашивать статус другой ноды.
4. Нода умеет передавать созданный блок другой ноде (Push) и запрашивать блок у другой ноды (Pull).
5. Перед добавлением внешнего блока выполняются проверки:
   - совпадение ожидаемого индекса (`last.index + 1`);
   - совпадение `prev_hash` с `hash` последнего локального блока;
   - валидность формата и `event_type` каждой транзакции;
   - совпадение `tx.hash == tx.compute_hash()` для каждой транзакции;
   - совпадение `block.hash == block.compute_hash()`.
6. При нарушении любого правила блок отклоняется без изменения локального хранилища с возвратом кода и текста ошибки.

## 2. Контракты API

| Метод и путь | Назначение | Успешный ответ |
|---|---|---|
| `GET /api/v1/node/info` | Метаданные ноды, высота, `genesis_hash`, `last_block_hash`, статус валидности, список пиров | `200 OK` |
| `GET /api/v1/chain/validate` | Полная диагностика локальной цепочки | `200 OK` |
| `GET /api/v1/peers` | Список известных адресов пиров | `200 OK` |
| `POST /api/v1/peers/register` | Регистрация пира (`url`, `verify_connection`, `bidirectional`) | `201 Created` |
| `DELETE /api/v1/peers?peer_url=...` | Удаление пира из списка | `200 OK` |
| `GET /api/v1/peers/inspect?peer_url=...` | Запрос состояния другой ноды + сравнение высоты и генезиса | `200 OK` |
| `GET /api/v1/blocks` | Полный список блоков ноды | `200 OK` |
| `GET /api/v1/blocks/latest` | Последний блок ноды | `200 OK` |
| `GET /api/v1/blocks/{index}` | Получение конкретного блока по индексу (для Pull) | `200 OK` |
| `POST /api/v1/blocks` | Создание локального блока (+ опциональный `broadcast: true`) | `201 Created` |
| `POST /api/v1/blocks/receive` | Приём и валидация блока от другой ноды (для Push) | `201 Created` |
| `POST /api/v1/blocks/{index}/broadcast` | Отправка блока пиру или всем пирам | `200 OK` |
| `POST /api/v1/blocks/fetch` | Запрос блока у другой ноды и добавление в локальную цепь (Pull) | `201 Created` |
